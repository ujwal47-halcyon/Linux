# Linux Learning — OverTheWire Bandit

## Progress

Completed OverTheWire Bandit levels **0 through 9** (10 levels).

This repository tracks practical Linux command-line learning through the Bandit wargame. The exercises covered navigating files and directories, handling unusual filenames, inspecting file types and permissions, searching with `find`, filtering text with `grep`, sorting and identifying unique lines with `sort` and `uniq`, and extracting readable strings from data files.

## Proofs

The `proofs/` directory is reserved for redacted screenshots documenting the level goals, terminal commands, and successful progression.

Screenshots must not contain readable Bandit passwords, tokens, or other credentials. Keep original unredacted screenshots private. Redacted proof images can be added here as a ZIP archive or individually.

## Scope

This is a learning log, not a claim of professional certification or completion of the entire Bandit wargame. Progress is currently recorded through level 9.
