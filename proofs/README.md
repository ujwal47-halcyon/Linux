# Bandit Proofs

Add the redacted proof images for Bandit levels 0–9 in this directory.

Suggested structure:
- `level-00-to-03/`
- `level-04-to-06/`
- `level-07-to-09/`

You can upload the supplied `bandit-levels-0-9-redacted-proofs.zip` here and extract it, or add the redacted JPG files individually.

Before committing, confirm that no Bandit password, SSH credential, token, or sensitive account information is readable. Keep original screenshots private.
